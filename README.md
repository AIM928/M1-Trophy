# M1 Trophy for Gunner, HEAT, PC!

M1 Trophy conversion with Trophy APS, M829A4, CITV and a remote weapon station.

## Install
Download **M1-Trophy-0.2.4-Full.zip** from [Releases](https://github.com/AIM928/M1-Trophy/releases/latest). Copy its `Mods` folder into the GHPC folder containing `GHPC.exe`. Requires MelonLoader. Keep both DLLs and `M1TrophyAssets` together; remove older duplicate M1 Trophy DLLs.

## Current build
- External mantlet: original armour plus fitted reinforcement totals 600 mm KE from the front; rear breech/mount excluded from this budget. Cheek calculation and visible geometry retained. These are game tuning values.
- Commander exterior camera: additional 0.5 m at the native camera output.
- Smoke: 12 rounds in 3 salvos of 4. Normal diagnostic spam disabled.
- Offline checks passed; live firing and camera verification remain pending. Compatibility depends on the GHPC version and other mods.
